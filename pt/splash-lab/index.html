Splash V2 — « Le Scan »

Concept : le glyph AAXLO est un disque découpé par des stripes. Ce splash fait de la stripe le fil narratif complet — une ligne de scan imprime le logo, puis se réincarne en première stripe de découpe du glyph. La fin (O → disque → stripes → -45° → glyph orange → header) est géométriquement identique à l'original.

En cours…

Storyboard

  1. 0.00sIgnitionUne ligne de scan orange pleine hauteur s'allume à gauche du logo — draw vertical + flicker néon.
  2. 0.30sLe ScanLa ligne balaie l'écran sombre et imprime les lettres blanches derrière elle. Chaque lettre traversée : settle vertical + flash d'un fantôme orange décalé (misregistration d'impression). Une règle de ticks techniques se révèle sous le logo.
  3. 0.88sLe FlipLa ligne finit de traverser le O → flip négatif en un cut dur : fond sombre → blanc, lettres blanches → dark, flash 1 frame + micro punch d'échelle.
  4. 0.95sO → DisqueLe O morphe en disque parfait pendant que la ligne de scan revient, rétrécit à la hauteur du disque et blanchit — elle devient la première stripe de découpe.
  5. 1.33sDécoupeLes 10 stripes (mêmes rects que l'original) cascadent depuis la ligne et découpent le disque.
  6. 1.63sRotationLe disque découpé tourne de -45° (elastic).
  7. 2.05sGlyphCrossfade vers le glyph orange #FF8270.
  8. 2.28sCollapseLe logo file se loger dans le header, le splash se clippe et révèle la page.

Notes d'intégration

  • Composant : app/components/SplashScreenV2.vue — GSAP + SVG pur, zéro dépendance ajoutée.
  • Pour promouvoir : remplacer <SplashScreen> par <SplashScreenV2> dans app/pages/index.vue (mêmes events @reveal / @complete), puis supprimer cette page.
  • Accessibilité conservée : bouton Skip, touche Échap, prefers-reduced-motion → skip immédiat.
  • Le collapse cible .header-logo .logo-img mesuré au runtime — fallback coin haut-gauche si absent.
